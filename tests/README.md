# 测试

纯标准库 `unittest`，无需 pytest 也能跑。

## 运行

```bash
# 方式1：直接跑
python tests/test_scoring.py

# 方式2：pytest（若已安装）
python -m pytest tests/ -v
```

## 覆盖范围

| 测试类 | 覆盖内容 |
|---|---|
| `TestFindLaunch` | ①建仓信号识别：涨停/放量阳线触发、放量阴线排除、连板排除、横盘无信号 |
| `TestTechScore` | ②整理不破位：正常蓄势得正分、跌破建仓低位得 -20 |
| `TestHeatScore` | 热度趋势：热门高分、冷门负分、数据不足归零、衰减扣分 |
| `TestConceptBonus` | 概念加成：热门概念加分、泛概念不计分、无匹配归零 |
| `TestIsGeneric` | 泛概念过滤：央国企改革等判泛、光刻胶等判具体 |

## 设计原则

- **不依赖数据库和外网**——用合成K线构造场景
- **测行为不测实现**——断言"跌破就-20"而非某个内部变量
- **边界优先**——阴线、连板、数据不足这些容易写错的分支都有用例
